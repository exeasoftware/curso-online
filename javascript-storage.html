Diferencias Clave y Serialización JSON
localStorage (Persistente)
  • Los datos permanecen guardados aunque cierres la pestaña, el navegador o reinicies la PC.
  • Solo se borran si el usuario limpia la caché o ejecutas localStorage.removeItem() / .clear().
  • Tip importante: Si guardas un JSON inicial en localStorage y luego modificas el archivo físico en disco, el navegador seguirá leyendo la copia vieja de localStorage hasta que la limpies o sobrescribas.
sessionStorage (Temporal por Pestaña)
  • Los datos viven únicamente mientras la pestaña esté abierta.
  • Al cerrar la pestaña o el navegador, toda la información se destruye automáticamente.
  • Ideal para controlar sesiones activas (como sessionStorage.setItem('usuario_activo', 'root')) y evitar accesos duplicados.
Regla de Oro: Web Storage solo almacena cadenas de texto (strings). Para guardar arreglos u objetos debes convertirlos antes con JSON.stringify(objeto), y al leerlos reconstruirlos con JSON.parse(texto).
