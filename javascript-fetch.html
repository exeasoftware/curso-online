Anatomía de una Petición Fetch

fetch() es la API nativa moderna de JavaScript para realizar peticiones de red asíncronas (reemplazando al antiguo XMLHttpRequest y complementando a $.getJSON() de jQuery).

Flujo en 2 pasos (Promesas):
  1. Respuesta HTTP: const res = await fetch(url) devuelve los encabezados y el estado (res.ok, res.status).
  2. Extracción del cuerpo: const datos = await res.json() convierte el flujo recibido en un objeto o arreglo JavaScript usable.
async function consultarDatos(url) {
  try {
    const respuesta = await fetch(url);
    if (!respuesta.ok) {
      throw new Error("Error HTTP: " + respuesta.status);
    }
    const datos = await respuesta.json();
    console.log(datos);
  } catch (error) {
    console.error("Fallo de red:", error);
  }
}
