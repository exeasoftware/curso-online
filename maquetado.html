Renderizado de Maquetación Interactivo

.box-model Modelo de Caja

El modelo de caja comprende el margen (margin), borde (border), relleno (padding) y el contenido real del elemento.

Código CSS en maquetado.css:

.box-model { margin: 20px; padding: 20px; border: 6px dashed #3b82f6; }
Consejo Pro de Maquetación:

Siempre inspecciona el Box Model en las DevTools del navegador para verificar cómo afectan los márgenes y rellenos.

Estructura de Archivos Separada para GitHub Pages

Para publicar correctamente este tutorial en GitHub Pages, debes crear dos archivos independientes en la raíz de tu repositorio: maquetado.html y maquetado.css.

maquetado.css 
/* ===================================================
   Cursos Online Exeasft - Hoja de Maquetación CSS
   Archivo: maquetado.css
   =================================================== */

/* Reset básico */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

body {
  font-family: 'Inter', sans-serif;
  background-color: #0f172a;
  color: #f8fafc;
}

/* 1. Box Model */
.tag-card-box {
  margin: 15px;
  padding: 20px;
  border: 4px dashed #3b82f6;
  background-color: #1e293b;
  border-radius: 8px;
}

/* 2. Flexbox */
.flex-container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 15px;
  padding: 15px;
  background-color: #1e293b;
  border-radius: 8px;
}

/* 3. CSS Grid */
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 15px;
  padding: 15px;
  background-color: #1e293b;
  border-radius: 8px;
}

/* 4. Posicionamiento */
.relative-box {
  position: relative;
  height: 100px;
  background-color: #334155;
  border-radius: 8px;
}

.absolute-badge {
  position: absolute;
  top: 10px;
  right: 10px;
  background-color: #ef4444;
  color: #ffffff;
  padding: 4px 10px;
  border-radius: 4px;
}

/* 5. Animaciones */
.card-hover {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
  cursor: pointer;
}

.card-hover:hover {
  transform: translateY(-5px);
  box-shadow: 0 10px 20px rgba(59, 130, 246, 0.3);
}

Pasos para publicar en GitHub Pages:

  1. Crea una carpeta en tu computador y guarda ambos archivos (maquetado.html y maquetado.css).
  2. Sube ambos archivos a tu repositorio público de GitHub.
  3. Ve a Settings > Pages en GitHub, selecciona la rama main y guarda.
  4. ¡Listo! Tu sitio cargará dinámicamente los estilos externos desde maquetado.css.
