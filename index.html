Parte 1: Fundamentos

¿Qué es HTML y cómo funciona?

HTML (HyperText Markup Language) es el lenguaje estándar utilizado para estructurar páginas web. No es un lenguaje de programación, sino un lenguaje de marcado basado en etiquetas que le indican al navegador web qué tipo de contenido está viendo.

Etiquetas (< >)

Instrucciones encerradas entre corchetes angulares que abren y cierran un elemento.

Atributos

Propiedades adicionales dentro de la etiqueta que modifican su comportamiento (ej: `src`, `href`).

Estructura

Jerarquía clara: un documento tiene cabeza (`head`) y cuerpo visible (`body`).

Anatomía de un elemento HTML
